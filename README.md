# Stock Market Analytics Dashboard

## 📊 Project Overview

An interactive stock market analytics project developed in Microsoft Excel to analyze stock performance, sector performance, trading activity, volatility, and investment-related insights.

The project includes data cleaning, data standardization, data modeling, KPI development, interactive dashboards, performance analysis, AI-assisted insights, and an executive investment report.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Power Query
- Power Pivot
- DAX
- PivotTables
- Slicers & Timelines
- Data Cleaning & Standardization
- Data Modeling
- Data Visualization
- AI-assisted Analysis

## 📈 Key Analysis

- Market capitalization analysis
- Average stock return analysis
- Stock-level performance comparison
- Sector-level performance comparison
- Trading volume analysis
- Return volatility analysis
- Closing price trend analysis
- Interactive dashboard with filters
- Executive investment reporting

## 🔍 Key Findings

- TCS recorded the highest average return at 109.11%.
- HDFCBANK recorded the lowest average return at -17.11%.
- IT recorded the highest average sector return at 82.75%.
- Banking recorded the lowest average sector return at -17.11%.
- Overall average return across the analyzed dataset was 19.82%.
- Total trading volume across the dataset was 113,650,000.

## ⚠️ Data & Analysis Note

The analysis is based on the provided historical dataset. Some extreme return observations are present in the dataset and should be investigated further before drawing real-world investment conclusions.

This project is for analytical and educational purposes and should not be interpreted as personalized investment advice.
